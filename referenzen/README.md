# Referenzen

Fotos aus **032c** (Cover, Ausgabe 11, 2006) und **The Red Bulletin**. Originale liegen hier, verkleinerte Fassungen für die Leinwand in `web/`. Nur als interne Inspiration, nicht zur Veröffentlichung.

## Was wir mitnehmen

**Typografie in drei Stimmen.** Eine fette Grotesk für alles Laute (Titel, Namen, Zitate, Seitenzahlen), eine Serif für langen Text, eine Mono für alles Kleine (Bildunterschriften, Fakten, Autorenzeilen). Die Mono macht die Seiten sofort „magazinig“.

**Fotos bis zur Kante.** Fotos stehen ganzseitig, laufen über den Bund oder füllen eine halbe Seite. Text geht direkt ins Bild: weiße Zitate, riesige Seitenzahlen, Titel in Versalien.

**Eine Farbe als Fläche.** Orange gibt es nicht als Akzent in Wörtern, sondern als ganze Seite, meist neben Schwarzweißfotos. Rot taucht nur in kleinen Rubriken auf („Reise/“).

**Wenig Kopfzeile.** Seitenzahl, Rubrik, Fußzeile mit dem Namen. Keine Linien, keine Kästen.
